# Registros de decisões de arquitetura

ADRs registram contexto, decisão e consequências. Decisão aceita não significa infraestrutura validada no Azure.

| Registro | Decisão | Estado |
| --- | --- | --- |
| [001](001-environments.md) | DEV/PROD separados com módulos compartilhados | Implementada em código |
| [002](002-remote-state.md) | Backend remoto e bootstrap independente | Preparado; não provisionado |
| [003](003-approved-execution.md) | Execução Azure somente aprovada | Regra vigente; deploy não implementado |

Se uma decisão mudar, preserve seu histórico e indique o registro que a substitui. Siga o [fluxo de contribuição](../../CONTRIBUTING.md).
